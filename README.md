# Kirk Patoucheas · Portfolio

Personal portfolio: product design and frontend engineering work, presented as scroll-driven project scenes with full case studies.

- Plain HTML, CSS and JavaScript in a single `index.html`, with images in `assets/`. No build step.
- Light and dark themes, responsive down to phone width, and a reduced-motion fallback.

## Run locally

```bash
python3 -m http.server 4321
```

Then open http://localhost:4321.
